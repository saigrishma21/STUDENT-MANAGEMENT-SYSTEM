# Student Management System

A Python-based Student Management System developed to manage and maintain student records efficiently. The project demonstrates core Python programming concepts such as variables, functions, Object-Oriented Programming (OOP), file handling, exception handling, JSON data storage, and Git version control.

## Features

- Add new student records
- View all student records
- Search students using Student ID
- Update student information
- Delete student records
- Calculate student average marks
- Calculate student grades
- Store student data permanently using JSON
- Handle invalid inputs and runtime errors
- Basic unit testing
- Git and GitHub version control

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling
- Exception Handling
- Git
- GitHub
- Pytest
